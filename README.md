A tiny Python program that writes one funny single-line one-star review from a house cat about its human to `/output/entry.txt`, for make.fun's "Make the AI Judge Laugh: Cat Reviews Its Human" bounty.

## The entry

> One star. He refills my bowl on time, but then sits in my sunbeam and talks to me while I eat. I did not order company with my kibble.

## Run it

```sh
python3 main.py
```
